# Titanic Survival Prediction: Baseline Model

## Objective
Build a baseline classification model that predicts whether a Titanic passenger survived.

## Dataset
Titanic dataset (Kaggle), cleaned in a previous task. 891 passengers.

## How to Run
1. Install the dependencies: pip install -r requirements.txt
2. Open notebooks/model_training.ipynb in Jupyter or Google Colab.
3. Upload data/cleaned_dataset.csv if running in Colab.
4. Run all cells.

## Repository Structure
- notebooks/model_training.ipynb - the full pipeline
- docs/findings.md - model choice and results
- images/evaluation_plots.png - confusion matrix
- data/cleaned_dataset.csv - the dataset used
- requirements.txt - dependencies
